# DreamZero accuracy parity

This page uses the [DreamZero-DROID](https://huggingface.co/GEAR-Dreams/DreamZero-DROID)
checkpoint to compare PhyAI and official DreamZero outputs on DROID-100,
and presents successful PhyAI runs in three simulation tasks. For model setup, see
the [single-GPU inference guide](/models/dreamzero/ws1).

## Results

### Action cosine similarity between PhyAI and the official implementation

Both implementations use the same observations, task instructions, and initial noise.
After denormalization and relative-action reconstruction, each request produces a
`24 × 8` action sequence containing seven joint positions and one gripper position.
The table below reports cosine similarity after concatenating and flattening the valid actions in each trajectory.

| Episode | Valid frames | Requests / implementation | PhyAI vs. official cosine |
| --- | ---: | ---: | ---: |
| 1 | 238 | 10 | `0.9999426405` |
| 3 | 205 | 9 | `0.9999509762` |
| 4 | 213 | 9 | `0.9996626058` |
| 13 | 196 | 9 | `0.9986872700` |
| **Overall** | **852** | **37** | **`0.9996187567`** |

### MAE and MSE against dataset demonstrations

PhyAI and official outputs are each compared with the target actions recorded in the dataset.
Reference actions come from `action_dict.joint_position` and `action_dict.gripper_position`.

| Episode | PhyAI MAE | Official MAE | PhyAI MSE | Official MSE |
| --- | ---: | ---: | ---: | ---: |
| 1 | `0.083682` | `0.082765` | `0.024105` | `0.023563` |
| 3 | `0.061379` | `0.060442` | `0.009379` | `0.009262` |
| 4 | `0.110278` | `0.111754` | `0.027401` | `0.028003` |
| 13 | `0.101529` | `0.105353` | `0.031230` | `0.032374` |
| **Equal-weight mean over four trajectories** | **`0.089217`** | **`0.090079`** | **`0.023029`** | **`0.023301`** |

MAE and MSE are first computed over all valid actions in each trajectory, then averaged
with equal weight across the four trajectories. The differences in mean error are shown below.
A negative `PhyAI − official` value indicates lower error for PhyAI; PhyAI achieves lower
mean action error on these evaluated trajectories.

| Metric | PhyAI − official |
| --- | ---: |
| Mean MAE | `−0.000861` |
| Mean MSE | `−0.000272` |

## Evaluation configuration

| Item | Configuration |
| --- | --- |
| Model checkpoint | `DreamZero-DROID` |
| Dataset | DROID-100, TFRecord `1.0.0` |
| Episodes | `1`, `3`, `4`, `13` |
| Model inputs | Three RGB cameras, joint and gripper states, dataset task instructions |
| Action output | `24 × 8` per request; only valid frames are scored at the end |
| Sampling mode | dynamic16, CFG `5.0`, seed `1140` |
| Numerical settings | BF16, TF32 disabled |

Episode indices follow the sorted TFRecord shard filenames and the record order within
each shard. Requests start at frames `0, 24, 48…`, comparing 24 actions from the current
frame. If fewer than 24 frames remain, only existing actions are included. The first
request uses a single image frame; subsequent requests use four historical frames at
offsets `[-23, -16, -8, 0]` relative to the current frame. The sequence and KV cache are
reset at the start of each episode, while history is retained within an episode.

## Simulation tasks

Using the same DreamZero-DROID checkpoint and dynamic16 configuration, PhyAI completed
a task execution in each of the following three scenes, with all runs judged successful.

The scenes use [sim-evals](https://github.com/arhanjain/sim-evals), with assets from
[DROID-sim-environments](https://huggingface.co/datasets/owhan/DROID-sim-environments).
Simulation runs on Isaac Sim 5 / Isaac Lab 2.2, with model inference on Thor.
The simulator provides camera images and robot states in real time. The model generates
actions conditioned on the task instruction, and 24 actions are executed before new
observations are collected.

| Scene | Task | Result | Simulation steps | Model requests |
| --- | --- | --- | ---: | ---: |
| Scene1 | Place the cube in the bowl | Success | 167 | 7 |
| Scene2 | Place the can in the mug | Success | 157 | 7 |
| Scene3 | Place the banana in the bin | Success | 284 | 12 |
